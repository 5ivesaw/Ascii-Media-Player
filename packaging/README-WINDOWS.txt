ASCII Media Player for Windows

1. Keep the EXE anywhere you can write files.
2. Open PowerShell or Windows Terminal in that folder.
3. Run:

   .\ASCII-Media-Player-v2.2.0-Windows-x64.exe "C:\Music"

Double-clicking the EXE also works and prompts for a music folder. FFmpeg is optional and is only required for formats that Pygame cannot decode directly. Install it with: winget install Gyan.FFmpeg
