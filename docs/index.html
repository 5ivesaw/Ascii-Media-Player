    02 / BUILT, NOT FAKED
    
        
    A complete player behind the visual system.
    
        
    The website and terminal application share the same local-first idea while using the strengths of each platform.
    
      
    
      
    
        
    01
    Real frequency analysis
    The browser player samples the current audio stream through an analyser node and maps it into a text spectrum or waveform in real time.
    
        
    02
    Local multi-track queue
    Add several files, reorder your listening with shuffle, repeat the current track, remove queue entries, and automatically continue to the next track.
    
        
    03
    Offline application shell
    The site caches its interface and artwork after the first successful visit. Selected audio remains local and is never stored by the application.
    
        
    04
    Desktop conversion pipeline
    The Python application uses FFmpeg to convert unsupported compressed files into deterministic cached WAV files without altering the originals.
    
        
    05
    Accessible controls
    Semantic controls, visible focus states, keyboard shortcuts, screen-reader labels, reduced-motion support, and responsive layouts are included.
    
        
    06
    Verified release pipeline
    Every version tag builds dedicated Windows, Linux, Android, and macOS artifacts, publishes checksums, and attaches everything to one GitHub Release.
    
      
    
    
    

    
    
      
    
        
    03 / RELEASE MATRIX
    
        
    One source. Native artifacts for every target.
    
        
    The release system builds on each operating system instead of pretending one executable is portable everywhere.
    
      
    
      
    
        
    WINDOWS
    Standalone EXE
    A native x64 console executable and ZIP package. Python is bundled; FFmpeg remains optional for conversion-only formats.
    ASCII-Media-Player.exe
    
        
    LINUX
    x64 and ARM64
    Portable binaries, tar archives, and a user-level installer for ordinary desktops, servers, and ARM Linux systems.
    curl installer | sh
    
        
    ANDROID
    Native APK shell
    The complete local web player is bundled inside an Android WebView app with multi-file selection, fullscreen, and offline operation.
    Install the signed APK
    
        
    MACOS
    Intel and Apple Silicon
    Separate native terminal binaries are built on Intel and ARM runners and packaged with a double-clickable command launcher.
    Choose the matching CPU

    06 / LOCAL BY DESIGN
    Your music never enters somebody else's machine.
    The web player creates temporary local object URLs and connects them to the browser's audio analyser. There is no media upload service, account database, telemetry SDK, or advertising code.
