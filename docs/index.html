WINDOWS / LINUX

cd Ascii-Media-Player
python -m pip install -r requirements.txt
python app.py /path/to/music
ANDROID

Open this page in Chrome or another PWA-capable browser.

Use the browser menu and choose Install app or Add to Home screen.
